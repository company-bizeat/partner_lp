# BizEat 飲食店パートナー募集 LP

法人会食・接待に特化した予約・決済プラットフォーム「BizEat」の飲食店向けパートナー募集 LP。Figma デザイン（飲食店パートナー向けLP）をもとに、HTML / CSS / Vanilla JS でピクセル忠実に実装しています。

## 特徴

- **デザイン準拠**: Figma デザイン（node 34:329）の全セクションを再現。カラー・タイポグラフィ・余白・角丸は Figma の実測値に基づく
- **デザインシステム**: Sparkle Design System の shadow（base / raise / float / stick / popOut）・radius トークンの命名思想に沿った CSS 変数レイヤーを定義
- **モーション**: スクロール連動フェードイン（IntersectionObserver）、カード/ボタン/ロゴチップのホバーリフト、スティッキーヘッダー、FAQ アコーディオン、ハンバーガーメニューのアニメーション、ヒーローキービジュアルのポインター連動チルト・グロー/リング装飾
- **レスポンシブ**: デスクトップ（1440px）〜モバイル（375px）対応。比較表はモバイルでラベル付きの1カラム表示に切り替え
- **お問い合わせフォーム**: 資料請求・加盟申し込み・掲載相談の3種別をセレクトボックスで選択できる `contact.html`。LP 側の各 CTA から `?type=` クエリで種別を事前選択した状態で遷移
- **アクセシビリティ**: セマンティック HTML、スキップリンク、`aria-expanded` 制御、`prefers-reduced-motion` 対応

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | LP 本体のマークアップ |
| `contact.html` | お問い合わせフォーム（資料請求 / 加盟申し込み / 掲載相談） |
| `styles.css` | デザイントークン + 全セクション・フォームのスタイル |

| `assets/` | Figma からエクスポートした画像・アイコン |

## FAQ の回答文について

Figma デザインには質問文のみが定義されていたため、回答文はページ内の既出コピー（メリット・比較表・お願い事項セクション）から矛盾なく導けるものに限定して作成しています。実運用前に事業側での内容確認を推奨します。

## お問い合わせフォームの送信設定（Formspree）

`contact.html` のフォームは [Formspree](https://formspree.io) の下記エンドポイントに送信されます。

```
https://formspree.io/f/maqrvbpn
```

- **送信先メールアドレス・自動返信メールの文面**: Formspree ダッシュボード → 対象フォームの **Settings** で設定します（本リポジトリのコードでは管理していません）
  - 送信先アドレスは Settings 内の宛先設定から変更可能です
  - 送信後の自動返信メール（件名・本文）は Settings 内の Autoresponse 機能で設定します（プランによって利用可否が異なるため、最新の料金ページでご確認ください）
  - メールの件名は `contact.html` 側の `<input type="hidden" name="_subject" value="...">` でも指定しています。変更したい場合はこの値を編集してください
- **初回送信時の注意**: Formspree は不正利用防止のため、そのフォームで最初の送信があったタイミングでフォーム所有者に確認メールを送ります。そのメール内のリンクを承認するまでは以降の送信が転送されないため、公開前に一度テスト送信し、確認メールを承認しておいてください
- 送信に失敗した場合（エンドポイント未設定・ネットワークエラーなど）は `contact.js` がフォーム内にエラーメッセージを表示します
